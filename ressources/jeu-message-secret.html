Statut : prototype interactif de travail. Le modèle 3D, les mots proposés, la correspondance lettres-trous, les formulations historiques et l'accessibilité doivent encore être validés avant une diffusion définitive.

Prudence historique

Le jeu s'inspire d'un principe antique de transmission de message avec un astragale percé. Cette version simplifie plusieurs éléments pour être compréhensible : interface numérique, lettres latines, mots courts et visualisation du fil.

Prototype jouable

Écris les mots guidés, puis passe au mode décodage : suis le fil, lis la carte lettres-trous et tape le mot trouvé.
