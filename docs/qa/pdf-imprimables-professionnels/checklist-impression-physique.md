# Checklist d'impression physique

Statut : **à réaliser**. Aucun essai sur imprimante réelle n'est revendiqué dans ce lot.

## Identification du test

- Date :
- Personne :
- Imprimante / copieur :
- Pilote et système :
- Papier : 80 g / 100 g / 120-160 g pour cartes / autre :
- Réglage : taille réelle 100 % / ajuster / autre :
- Couleur ou niveaux de gris :
- Recto simple ou recto-verso :

## Échantillon minimal

- [ ] Activité 1 : fiche élève complète.
- [ ] Activité 2 : guide d'encadrement et une page de cartes A-D.
- [ ] Activité 3 : supports en niveaux de gris.
- [ ] Activité 4 : kit complet, au moins les pages de couverture, fiche, cartes et corrigé.

## Format et marges

- [ ] Toutes les feuilles sortent en A4 portrait.
- [ ] Aucun titre, pied de page, numéro ou trait n'est rogné.
- [ ] Les marges restent régulières sur plusieurs imprimantes si possible.
- [ ] Le recto-verso avec retournement bord long conserve le bon sens de lecture.
- [ ] L'ordre du kit est : couverture, guide, fiche, supports, corrigé, sources.

## Lisibilité

- [ ] Le corps du texte est confortable à distance normale de lecture.
- [ ] Les crédits restent lisibles sans prendre le dessus sur l'activité.
- [ ] Les statuts « pilote », « à valider » et « à compléter » sont compréhensibles sans couleur.
- [ ] Les lignes et zones de réponse sont visibles, mais assez légères pour écrire dessus.
- [ ] Les tableaux conservent toutes leurs colonnes et leurs bordures.
- [ ] Les liens imprimés ne créent pas de longue URL parasite.

## Images et niveaux de gris

- [ ] Le talus rouge reste repérable grâce aux légendes en niveaux de gris.
- [ ] Les détails des œuvres de l'activité 3 restent discernables.
- [ ] Les images ne sont ni pixelisées, ni trop sombres, ni coupées.
- [ ] Les hachures des emplacements neutres A-D et A-E restent distinctes.
- [ ] Aucune image provisoire exclue ne réapparaît dans le lot.

## Découpe et usage

- [ ] Les pointillés des cartes sont utilisables avec des ciseaux ordinaires.
- [ ] Deux cartes placées sur une même page ne se chevauchent pas.
- [ ] Les zones d'écriture sont suffisantes pour des élèves de 8 à 12 ans.
- [ ] Le guide peut être manipulé rapidement pendant une séance.
- [ ] Le kit complet peut être agrafé ou relié sans masquer le texte.

## Résultat

- [ ] Validé sans correction.
- [ ] Validé avec corrections mineures.
- [ ] Nouvelle génération nécessaire.
