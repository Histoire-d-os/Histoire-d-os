# QA des PDF imprimables professionnels

Ce dossier documente le contrôle du lot pilote généré le 20 juillet 2026.

## Contenu

- `contact-sheets/` : une planche de contrôle par PDF et par langue ;
- `grayscale/` : contrôles représentatifs en niveaux de gris ;
- `pages.csv` : dimensions et volume de texte par page ;
- `test-results.json` : résultats automatisés par fichier ;
- `overflow-report.md` : synthèse des pages, débordements et pages vides ;
- `checklist-impression-physique.md` : protocole à compléter sur une imprimante réelle.

Les 496 pages des 80 PDF ont été rendues en PNG pendant l'audit. Les PNG page par page sont reproductibles et ignorés par Git afin de ne pas alourdir le dépôt ; les planches de contact et les résultats structurés sont conservés.

Ces preuves de contrôle interne ne remplacent ni la relecture humaine des contenus et traductions, ni le test d'impression physique.
