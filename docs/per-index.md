# Index PER provisoire du projet Histoire d'os

Document interne de préparation. Cet index repère les points d'appui possibles dans les documents PER déposés dans `_private-inputs/per/`, sans valider définitivement les alignements pédagogiques. Dans les tableaux, les fichiers sont nommés sous la forme `per/...` pour indiquer leur emplacement relatif dans le dossier privé. Les formulations devront être relues par une personne enseignante ou formatrice avant publication.

## Points à ne pas publier sans validation

- Les références PER doivent être reformulées comme des correspondances pédagogiques possibles, pas comme une homologation officielle.
- Les libellés exacts d'objectifs PER doivent être vérifiés avant toute page publique.
- Les activités ne couvrent pas automatiquement l'ensemble d'un objectif PER : elles en mobilisent seulement certains gestes, contenus ou démarches.
- Les documents PER privés restent dans `_private-inputs/per/` et ne doivent pas être copiés dans le site ou les ressources publiques.
