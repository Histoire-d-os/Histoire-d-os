# Plan de finalisation des cinq activites francaises

Ce plan commence apres relecture et acceptation du diagnostic. Chaque mission
future doit partir d'un arbre Git propre, appliquer les agents indiques avant et
apres modification, puis produire un commit separe seulement apres validation du
perimetre.

## Principes d'ordre

1. Corriger les erreurs de source et choisir une source canonique avant toute
   regeneration.
2. Stabiliser chaque corpus avant de dessiner les supports correspondants.
3. Tester le contenu avant les traductions et avant le transfert WordPress.
4. Examiner les droits du fichier exact, pas seulement ceux de l'oeuvre ou du
   texte scientifique.
5. Conserver les statuts pilotes jusqu'aux validations humaines.

## Regle de maturite

Une activite ne passe au niveau suivant que si les criteres du niveau precedent
sont documentes :

- niveau 0 : idee seulement ;
- niveau 1 : structure ;
- niveau 2 : prototype ;
- niveau 3 : test adulte possible ;
- niveau 4 : test avec eleves possible ;
- niveau 5 : validation scientifique possible ;
- niveau 6 : diffusion pilote ;
- niveau 7 : publication finale.

La presence d'un PDF ou d'un DOCX techniquement propre ne modifie pas a elle
seule le niveau de maturite.
