# Amélioration des guides enseignants / médiateurs

## Résumé

Les quatre guides imprimables ont été harmonisés pour être utilisables sans relire la page web de l'activité. Chaque guide indique désormais quoi préparer, comment conduire la séance, comment adapter l'activité en musée, quoi observer pour une évaluation rapide, comment différencier et quelles relances utiliser.

Les formulations restent prudentes : les cartes d'os A-D de l'activité 2, le corpus antique de l'activité 3 et les objets A-E de l'activité 4 restent signalés comme provisoires ou à valider.

- Vérification d'un seul `h1` par guide.
