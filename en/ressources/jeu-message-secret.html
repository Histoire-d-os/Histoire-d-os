Interactive game — encode a message with a knucklebone

A pierced bone can hide a message. In this prototype, you write and then decode words by following a thread between holes in an astragalus.

Status: working interactive prototype. The 3D model, proposed words, letter-hole mapping, historical wording and accessibility still require validation before final release.

Historical caution

The game is inspired by an ancient principle of message transmission with a pierced astragalus. This version simplifies several elements for learners: digital interface, Latin letters, short words and a visible thread.

Playable prototype

Write the guided words, then switch to decode mode: follow the thread, read the letter-hole map and type the word you find.
