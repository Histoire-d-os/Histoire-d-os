One bone, several lives

Observe an object, suggest hypotheses and check what can really be known.

Summary

Learn to describe a bone or object before interpreting it, distinguish what is observed from what is supposed, and understand that one object can have several possible uses depending on context.

What learners do

  • Observe before naming the answer.
  • Compare visible clues and justify a hypothesis.
  • Separate what is certain, probable or still to be checked.

Expected outcome

By the end of the activity, learners should be able to describe an object without assigning a function too quickly, propose at least two argued hypotheses, then write a cautious label sentence that separates what is observed, what is supposed and what still needs checking.

Recommended classroom sequence

  1. 1Present the object or card

    Show a support without announcing its function. First ask: "What do you see?"

  2. 2Observe only

    Learners note material, shape, traces, position, number or visible details without interpreting.

  3. 3Suggest several hypotheses

    They use cautious words: "perhaps", "could", "seems compatible with".

  4. 4Ask what is missing

    Learners identify what would help check the idea: label, provenance, dating, comparison, analysis or expert review.

  5. 5Write a cautious label

    Each group writes a short sentence separating observation, hypothesis and uncertainty.

Museum adaptation

In a museum, this activity works well in front of a real object, a replica or a documented photograph. The facilitator can ask visitors to write a mini museum label that distinguishes what they see, what they suppose and what would need checking.

Useful questions: "What is visible?", "What is a hypothesis?", "Which information is missing to write a more reliable label?"

Current version / final goal

Current version: usable as a method workshop. The steps of observation, hypothesis and cautious conclusion are usable, but cards A-E do not yet present real documented archaeological objects.

Final goal: integrate validated objects or replicas, with image, label, provenance, dating, licence, context and cautious interpretation for each card.
