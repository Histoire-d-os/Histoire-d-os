## Métadonnées à renseigner pour chaque image

- Auteur ou autrice.
- Collection ou institution.
- Numéro d'inventaire.
- Titre ou description de l'objet.
- Date de prise de vue ou de publication.
- Lien stable.
- Droits et licence.
- Recadrage effectué.
- Retouche effectuée.
- Texte alternatif élève, sans révéler la fonction.
- Texte alternatif adulte, avec contexte si nécessaire.
- Usage prévu : élève, adulte, guide, correction ou communication.

## Modèles 3D

Recherche locale effectuée dans le dépôt pour `.glb`, `.gltf`, `.obj` et `.stl` : aucun modèle 3D validé n'a été trouvé au moment de la création de l'activité 4. Aucun modèle n'a donc été généré, téléchargé ou lié.

Un futur modèle devra préciser : objet représenté, original ou reconstruction, institution, méthode de numérisation, échelle, orientation, modifications numériques, licence et validation scientifique.
