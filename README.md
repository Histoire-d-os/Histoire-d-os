# Histoires d'os

Première version statique du site du projet **Histoires d'os**, construit autour de l'astragale comme objet-pivot entre sciences du vivant, archéozoologie, histoire culturelle et médiation.

## Structure

- `index.html` : page principale du site.
- `styles.css` : direction visuelle et mise en page.
- `script.js` : navigation mobile, onglets de parcours et filtre du glossaire.
- `assets/hero-astragale.png` : visuel d'accueil généré pour le projet.
- `assets/logo-officiel-histoires-dos.jpg` : logo officiel du projet.
- `ressources/` : premières fiches d'activités, glossaire de départ et corrigé raisonné.

Le site fonctionne sans dépendances et peut être ouvert directement dans un navigateur.

## Ligne editoriale

Le site part de l'idée que l'osselet est d'abord un os. Il évite le raccourci "premiers dés" et organise les contenus autour de trois gestes pédagogiques : observer, situer, interpréter.
